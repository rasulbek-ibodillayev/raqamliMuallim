Rekursiv funksiya xotira murakkabligi bo‘yicha tuzilgan savolda Call Stack limiti qanday hisoblanadi?

Quyida keltirilgan rekursiv algoritm tahlili va Python standart interpretatoridagi chaqiruvlar stekining cheklovi asosida savolga javob bering:

terminal rekursiya_stack.py Python 3.11 
import sys

# Standart limit: sys.getrecursionlimit() = 1000
def hisobla_faktoriyel(n):
    # Bazaviy holat (Base case)
    if n <= 1:
        return 1
    return n * hisobla_faktoriyel(n - 1)

# Savol: n = 1500 bo'lganda RecursionError yuz beradi. 
# Stack freymlari xotira murakkabligi qanday baholanadi?
check_circle
Rasmiy to‘g‘ri javob va metodik asos

To‘g‘ri javob: O(N) xotira murakkabligi. Har bir chaqiruv operatsion tizim Call Stack xotirasida alohida freym (frame) yaratadi. Python interpretatori cheklovi sys.setrecursionlimit() bilan oshirilmaganda 1000 tadan oshgach RecursionError yuzaga keladi. O‘qituvchilar dars jarayonida quyruq rekursiyasi (Tail Recursion) va iterativ yondashuv farqlarini tushuntirishlari tavsiya etiladi.
