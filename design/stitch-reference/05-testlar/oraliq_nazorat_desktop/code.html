Quyidagi Python dastur kodi rekursiv usulda chaqirilganda, ekranda qanday natija chop etiladi?

Funksiyaning asosiy qadamlari, argumentning kamayish qonuniyati hamda bazaviy shartning (base case) bajarilish holatini tahlil qiling.

Python 3.11 
def hisobla(n):
    if n <= 1:
        return 1
    return n * hisobla(n - 2)

print(hisobla(5))
