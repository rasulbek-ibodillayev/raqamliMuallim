if operatori

Python dasturlash tilida shart operatorlari ma‘lum bir mantiqiy ifodaning rost (True) yoki yolg‘on (False) ekanligiga qarab dastur oqimini turli yo‘nalishlarga yo‘naltirish uchun ishlatiladi.

Agar tekshirilayotgan shart qanoatlantirilsa, unga tegishli kod bloki ishga tushadi. Aks holda, kod bloki tashlab ketiladi yoki muqobil qism bajariladi.

Python 
yosh = 18
if yosh >= 18:
    print("Kirishga ruxsat berildi")
else:
    print("Kirish taqiqlanadi")
