Funksiyalar va rekursiya: Chuqurlashtirilgan tahlil

timer 15 daqiqa qayta o'qish

Informatika fanida rekursiya — bu funksiyaning o'z-o'ziga to'g'ridan-to'g'ri yoki bilvosita murojaat qilish jarayonidir. Har qanday rekursiv algoritm ikkita majburiy asosiy komponentdan iborat bo'lishi shart:

  1. Bazaviy to'xtash sharti (Base Case): Hisoblash to'xtashi va funksiya zanjiri teskari qaytishi lozim bo'lgan minimal chegara.
  2. Rekursiv qadam (Recursive Step): Masalani o'ziga o'xshash, ammo hajmi kichikroq bo'lakka keltirib, funksiyani yana chaqirish.

Rekursiyada bazaviy shartni unutish oqibatlari (RecursionError)

Agar rekursiv funksiyada bazaviy to'xtash sharti qo'yilmasa yoki hech qachon bajarilmaydigan mantiq yozilsa, dastur har bir chaqiruvni kompyuter xotirasidagi Chaqiruvlar steki (Call Stack)ga qo'shib ketaveradi. Python interpretatori ushbu xatolikning oldini olish maqsadida sukut bo'yicha cheklov (odatda 1000 ta qatlam) o'rnatgan bo'lib, me'yor buzilganda quyidagi tizim xatoligini chiqaradi:

# Bazaviy chegara mavjud
def faktorial(n):
    if n <= 1:
        return 1  # Base Case
    return n * faktorial(n - 1)

Lokal va Global o'zgaruvchilar chalkashligi

Funksiya ichida e'lon qilingan o'zgaruvchi faqat o'sha funksiyaning lokal xotirasida yashaydi. Tashqi muhitdan lokal o'zgaruvchiga murojaat qilish NameError xatoligini vujudga keltiradi. Global o'zgaruvchini funksiya ichida yangilash uchun esa albatta global kalit so'zi ko'rsatilishi shart.
