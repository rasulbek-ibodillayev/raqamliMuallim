Funksiyalar va rekursiya: Stek va bazaviy shart

Oxirgi tahrir: Bugun, 14:20 · Muallif: Dilnoza Karimova · To'liq tayyorgarlik darajasi

1. Rekursiya nima va uning asosiy elementlari

Rekursiv funksiya deb o'z-o'zini chaqiruvchi algoritmik tuzilmaga aytiladi. Matematik induksiya prinsipi kabi har bir rekursiv chaqiruv muammoni kichikroq bo'lakka ajratadi va oxir-oqibat to'xtash nuqtasiga — bazaviy shartga (base case) yetib boradi.

Agar bazaviy shart to'g'ri belgilanmasa yoki parametrlar unga yaqinlashmasa, dastur cheksiz rekursiyaga tushadi va kompyuter xotirasidagi qo'ng'iroqlar steki (Call Stack) to'lib ketadi. Python muhitida bu holat RecursionError: maximum recursion depth exceeded xatoligini keltirib chiqaradi.

faktorial.py (Python 3.11) 
def faktorial(n):
    if n <= 1:      # Bazaviy shart (To'xtash nuqtasi)
        return 1
    return n * faktorial(n - 1)  # Rekursiv qadam (Stek chaqiruvi)

# Misol sinovi
print(faktorial(5))  # Natija: 120
