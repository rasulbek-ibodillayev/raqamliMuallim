psychology1. Memoizatsiya (Top-Down)

Masalani yuqoridan boshlab rekursiv bo'lib boradi, hisoblangan natijalarni keshda (lug'at/ro'yxat) eslab qoladi. "Bilganimni qayta hisoblamayman" prinsipi.

table_chart2. Tabulyatsiya (Bottom-Up)

Eng sodda bazaviy qiymatlardan (0 va 1) boshlab jadval shaklida natijani bosqichma-bosqich to'ldirib boradi. Rekursiv chaqiruv xarajatlari bo'lmaydi.

code python — memo_fib.py
def fib_memo(n, memo={}):
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]
