1.3-mavzu: Funksiyalar, rekursiya va modullar

Ushbu darsda dasturiy kodni mantiqiy bloklarga ajratish, qayta ishlatiluvchi funksional bloklar tuzish hamda kompyuter fanining fundamental usullaridan biri bo'lgan rekursiv yondashuvni tahlil qilamiz.

1. Funksiya tushunchasi va 'def' kalit so'zi

Dasturlashda funksiya — bu ma'lum bir mantiqiy vazifani bajarish uchun birlashtirilgan ko'rsatmalar to'plamidir. Funksiyalar kodning takrorlanishini kamaytiradi (DRY — Don't Repeat Yourself tamoyili), o'qilishini yaxshilaydi va murakkab muammolarni kichik qismlarga (dekompozitsiya) ajratish imkonini beradi.

Python dasturlash tilida funksiya def (inglizcha define — aniqlamoq) kalit so'zi yordamida e'lon qilinadi. Qavslar ichida funksiya qabul qiladigan parametrlar belgilanadi, ixtiyoriy ravishda standart parametr qiymatlarini belgilash ham mumkin.

daraja.py 
def daraja_hisobla(asos, daraja=2):
    """Berilgan sonning darajasini qaytaradi"""
    return asos ** daraja

print(daraja_hisobla(5))      # Natija: 25
print(daraja_hisobla(3, 3))   # Natija: 27
info
Muhim qoida: Standart parametrlar joylashuvi

Standart qiymatga ega bo'lgan parametrlar doimo ixtiyoriy (majburiy bo'lmagan) tartibda oxirida joylashishi shart. Aks holda Python kompilyatori SyntaxError: non-default argument follows default argument xatoligini keltirib chiqaradi.

2. Rekursiv funksiyalar va bazaviy shart

Rekursiya — bu funksiyaning o'z-o'zini chaqirishi bilan bog'liq dasturlash uslubidir. Matematik ketma-ketliklar, daraxtsimon ma'lumotlar tuzilmalari (trees) va bo'lib tashla hamda hukmronlik qil (divide-and-conquer) algoritmlarida rekursiya juda qulay vositadir.

Har qanday rekursiv funksiyaning yuragi bu uning bazaviy shartidir (base case). Bazaviy shart funksiyaning qachon to'xtashini belgilaydi. Agar bazaviy shart noto'g'ri berilsa yoki umuman belgilanmasa, dastur cheksiz chaqiruvga tushib, operatsion xotiradagi chaqiruvlar stekini (Call Stack) to'ldirib yuboradi va RecursionError: maximum recursion depth exceeded xatosi ro'y beradi.

rekursiya_faktorial.py 
def faktorial(n):
    # Bazaviy shart: to'xtash nuqtasi
    if n <= 1:
        return 1
    
    # Rekursiv chaqiruv: masalani soddaroq holatga keltirish
    return n * faktorial(n - 1)

print(faktorial(5))  # Natija: 120
